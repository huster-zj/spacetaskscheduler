# 延期工作

## Story 1.2 评审延期项

- **未保存内容保护：** 新建、打开规划包及跨页面离开前增加脏数据检测与确认流程，并明确导航失败时当前工作区的保留规则。
- **运行期间操作锁定：** 算法预处理和运行期间禁止新建、打开或切换规划包，避免前端状态与后端计算输入不一致。
- **多标签页与多用户隔离：** 当前启发式后端共用固定输入输出文件。需要重新设计 API 和后端任务隔离机制，为每次运行分配独立工作目录或任务标识后再支持并发。

## 工程基线重构评审延期项

- **依赖安全与锁定：** 分阶段升级前端高风险依赖及 FastAPI、Starlette、httpx，并为 Python 建立可重复的锁定文件；升级前需覆盖现有 API 与预处理回归。
- **上传与长请求保护：** 为 JSON/CSV 导入增加文件大小、CSV 文件角色与精确数量校验，并为转换和预处理请求提供超时、取消及恢复机制。
- **求解器集成验收：** 在具备许可证的受控环境增加 COPT 冒烟作业，并为 Java 启发式算法增加最小输入输出集成检查；公开 CI 继续保持无密钥。
- **Python 代码规范基线：** 迁移 `backend/ruff.toml` 的旧版配置表并清理现有告警，再将 Ruff 作为 CI 必需检查。
