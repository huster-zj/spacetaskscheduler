# 航天任务调度工具 - Experience Spine

## Foundation

单一响应式 Web 应用，桌面/笔记本为主要使用环境，平板和手机支持查看与基础操作。继续使用 Vue 3、Vue Router、Pinia 与 Ant Design Vue；`DESIGN.md` 是视觉规范，本文件定义信息架构和交互行为。

## Information Architecture

| 区域 | 页面 | 目的 |
|---|---|---|
| 工作台 | `/`、`/attributes` | 查看历史规划包、创建或编辑规划包属性 |
| 主视图 | `/main_view`、`/result` | 在资源、任务和日程视图间切换并检查调度结果 |
| 资源 | `/resource`、`/resource_group` 及详情页 | 导入、定义、分组和检查资源 |
| 任务 | `/task`、时态/逻辑约束及详情页 | 导入、定义任务并维护约束 |
| 调度 | `/operating`、`/report`、`/report_content/:type` | 选择目标和算法、运行并查看报告 |
| 帮助 | 外部帮助、许可证、关于链接 | 打开既有外部资料 |

全局导航始终暴露一级工作区。规划步骤条是流程导航，不替代全局导航。

## Voice and Tone

使用简洁、专业、直接的中文。保留既有业务术语，如“时态约束”“逻辑约束”“规划包”“可行时间窗”。反馈描述动作结果，不增加宣传式文案或感叹式鼓励。

## Component Patterns

| 组件 | 行为规则 |
|---|---|
| 全局导航 | 点击路由项保持现有目标；打开、另存为、下载继续调用原处理函数；外部链接新窗口打开。 |
| 步骤条 | 点击可达步骤跳转到原路由；当前不可达步骤保持无跳转行为。 |
| 数据表 | 搜索、筛选、选择、详情、删除和分页行为保持原样；视觉变化不得改变列、数据或事件。 |
| 表单 | `v-model`、校验、提交、Store patch 与跳转顺序保持原样。 |
| 视图切换 | 主视图的资源/任务/日程切换与皮肤开关保持原状态逻辑。 |
| 运行与报告 | 算法限制、接口调用、消息和结果弹窗保持原逻辑。 |

## State Patterns

| 状态 | 处理 |
|---|---|
| 当前路由 | 全局导航显示选中态，并保持键盘焦点可见。 |
| 加载/运行 | 继续使用现有 Ant Design loading/message/modal。 |
| 空数据 | 表格保持 Ant Design 空状态，页面布局不塌陷。 |
| 错误 | 保留原错误消息与业务分支，不吞掉异常。 |
| 窄屏 | 导航和表格局部横向滚动，按钮和文本不互相覆盖。 |

## Interaction Primitives

- 鼠标与键盘都可完成全局导航和主要表单操作。
- `Tab` 顺序遵循页面阅读顺序；`Enter` 激活链接/按钮；`Esc` 由 Ant Design 关闭顶层弹窗。
- 图标按钮必须有 `title` 或可访问名称。
- 禁止只在 hover 时提供唯一操作入口。

## Accessibility Floor

- 目标为 WCAG 2.2 AA 的基础可用性：正文和关键控件保持足够对比度。
- 所有交互元素具有可见 `:focus-visible` 样式。
- 普通命令触控目标至少 36px；移动端关键动作至少 44px。
- 不依赖颜色单独传达错误、当前项或完成状态。
- 响应式布局不得导致文本、按钮和表格工具栏重叠。

## Responsive & Platform

| 视口 | 行为 |
|---|---|
| `>= 1200px` | 完整品牌栏和分组导航；内容最大宽度 1920px。 |
| `768-1199px` | 分组导航横向滚动；页面边距收窄；双列表允许各自滚动。 |
| `< 768px` | 品牌副标题可隐藏；命令导航保持一行滚动；表单列堆叠；表格区域内部滚动。 |

## Key Flows

### Flow 1 - 建立规划包并进入任务调度

1. 规划人员在工作台打开或新建规划包。
2. 编辑规划包属性并保存。
3. 依次进入资源、资源组、任务和约束页面。
4. 在运行页选择当前支持的算法并执行。
5. **完成点：** 主视图和报告页展示现有算法结果，业务行为与重构前一致。

### Flow 2 - 检查并修正资源/任务定义

1. 规划人员从全局导航进入资源或任务列表。
2. 搜索、导入或进入详情页。
3. 修改现有字段并保存。
4. 返回列表继续检查约束。
5. **完成点：** 原有数据仍通过同一 Store/API 更新，界面层级和当前路径更清晰。
