# UX Decision Log

## 2026-08-14

- 采用桌面优先、响应式可用的专业调度工具方向，避免营销页式大标题和装饰性视觉。
- 继续使用 Vue 3、Ant Design Vue 3.2 和现有图标体系，不新增 UI 依赖。
- 视觉改造集中在全局 token、应用外壳、导航、步骤条、表格和表单，业务状态、接口和数据结构不变。
- 主色使用深青蓝，配合中性灰、青绿成功色、琥珀警告色和红色错误色，避免单一色相界面。
- 页面在桌面保持较高信息密度；窄屏允许数据表区域内部横向滚动，但应用外壳和控件不得重叠。
- [ASSUMPTION] 当前 logo 与中英文产品名继续作为品牌资产使用。
- [ASSUMPTION] 本次只交付浅色主题，暗色主题不在 Story 1.1 范围内。
